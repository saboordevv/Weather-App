# 🌦️ WeatherX - Modern Weather App

A modern, responsive, and aesthetically designed weather application built with **HTML**, **CSS**, and **JavaScript**. WeatherX provides real-time weather information using the **WeatherAPI** and features a beautiful dark glassmorphism user interface.

## ✨ Features

- 🌍 Search weather for any city worldwide
- 📍 Detect and display current location weather
- 🌡 Real-time temperature
- 🤗 Feels Like temperature
- ☁ Weather condition & icon
- 💧 Humidity
- 💨 Wind Speed
- 📊 Pressure
- 👁 Visibility
- 🌅 Sunrise
- 🌇 Sunset
- ☁ Cloud Percentage
- 🕒 Local Time
- 📅 Hourly Forecast
- 🌑 Modern Dark Theme
- ✨ Glassmorphism UI
- 📱 Fully Responsive Design
- ⚡ Fast API Integration
- 🔔 Toast Notifications
- ⌨ Search using Enter key

# 🔑 Weather API

This project uses **WeatherAPI**.

Create your free API Key from:

https://www.weatherapi.com/

Replace the API key inside:

```javascript
const API_KEY = "YOUR_API_KEY";
```
